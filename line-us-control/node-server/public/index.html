Drawing

    Plot

    Pen height
    1. Press Read to load the stored values, then Seat pen. Loosen the pen, let it rest on the paper, tighten it, then Raise.
    2. For each corner, press Start. The pen steps down, drawing a short dash. Press Stop as soon as ink appears.
    3. Press Save to store the four heights on the plotter.

    Home calibration

    Press Go home, nudge the pen until it sits over the small hole in the base plate, then press Save home.

    Wi-Fi & machine

    To set up Wi-Fi: hold the plotter's button for 2 s until it flashes red, join the Line-us-Setup network, and connect here (try 192.168.4.1 if line-us.local isn't found).
