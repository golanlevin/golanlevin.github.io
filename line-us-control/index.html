Drawing

Pen pressure from Z. Your file's Z values are converted to plotter heights, from 1000 (pen fully up) to 0 (pressing hardest). The pen just touches the paper at about 400.

    Plot

    Keep this tab open while plotting. Closing it stops the plot.

    Pen height
    1. Press Read to load the stored values, then Seat pen. Loosen the pen, let it rest on the paper, tighten it, then Raise.
    2. For each corner, press Start. The pen steps down, drawing a short dash. Press Stop as soon as ink appears.
    3. Press Save to store the four heights on the plotter.

    Wi-Fi setup

    In order to receive drawings, the Line-us plotter needs to join your local Wi-Fi network. However, telling the plotter which Wi-Fi to join can't be done from this page: the plotter only accepts this information over a direct connection, which a web browser can't make. Instead, it takes one terminal command and just a few seconds. You only need to do this once per network.

    Line-us can only join 2.4 GHz networks with WPA2-Personal (password-only) security, such as a home Wi-Fi or a phone hotspot. Networks that need a username as well as a password, such as eduroam, won't work.

    1. Hold the plotter's button for about 2 seconds, until its light flashes red (setup mode).
    2. On your computer, join the Line-us-Setup Wi-Fi network.
    3. Fill in your network's name and password, below. This information stays local.
    4. Open the Terminal app and run this (click Copy, paste, press Enter). nc opens a network connection, similar to telnet. 192.168.4.1 is the Line-us's own address while it's in Wi-Fi setup mode.
    5. Wait a few seconds for the arm to wave and a hello… line to appear. Then paste this line and press Enter:
      The light turns solid blue when it joins. If it flashes red, the password was wrong, so try step 5 again.
    6. Done. Close the Terminal window (press Ctrl-C first), and rejoin your normal Wi-Fi. The plotter is now at line-us.local — connect to it at the top of this page.

    On Windows, use PuTTY in "Raw" mode (host 192.168.4.1, port 1337) instead of the Terminal command in step 4, then type the line from step 5.

    Machine

    Rename the plotter (letters, digits and hyphens). After renaming, restart the plotter, then reconnect: put the new name plus .local in the address box at the top of this page. For example, if you rename it to studio-plotter, connect to studio-plotter.local.
